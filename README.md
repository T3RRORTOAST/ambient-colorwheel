# Ambient

Eine App für die Ambientebeleuchtung auf iDrive 7: `apps/gs_ambient`.

Der MGU App Store lädt dieses Repo auf die Headunit. Quelle `T3RRORTOAST/ambient-colorwheel`, Branch `main`. Gebaut wird dort mit `kit/tools/build.py`. Das BMW-SDK (`oap-sdk`) liegt nicht im Repo.

Mit der App kommen der GPU-Renderer und das Controller-Gate aus `kit/renderd/prebuilt`.

Emulator, die übrigen Kit-Apps, Logs und die alte Doku liegen lokal unter `../ambient-colorwheel-local` und gehen nicht mit aufs Auto.
